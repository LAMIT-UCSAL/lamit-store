LAMIT has two brand sources that conflict. One is the institutional guide in `assets/lamit-brand-skill/` (scrapbook style, Montserrat, #0A69C4/#E8722C/cream, "avoid tech gradients"). The other is `lamit-site/DESIGN.md` ("Hackathon Broadcast": BB Manual Mono uppercase, black canvas, Grainient WebGL cobalt #0A3383/amber #C17402, Signal Blue #164194, Signal Orange #e84b13, gold #d7c06b, 0 radius, no shadows). The store was built on the institutional guide.

**Why:** On 2026-10-13 the user said the store felt "too simple" and not part of the same ecosystem as the site. They want the store to STAY light-themed but inherit the site's identity. Audit: `docs/audits/2026-10-13-design-alignment-audit.md` (proposes "Broadcast em papel": light tokens, gold-ink #7D6310 and orange-ink #B83A0C for AA text).

**How to apply:** For store visual work, follow the site's language translated to light, not the scrapbook guide, unless PO/user reverses it. Open items: BB Mono web licence for the store domain, and an update to the store's PRODUCT.md Brand Commitments.
