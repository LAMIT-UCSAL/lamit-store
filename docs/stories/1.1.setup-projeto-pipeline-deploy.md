## Story

**As a** mantenedor do projeto,
**I want** ter a estrutura básica do site e um pipeline de deploy automático no Netlify configurados,
**so that** qualquer mudança no repositório vá ao ar de forma confiável e seja possível validar progresso em produção desde o início.

## Acceptance Criteria

1. Repositório contém a estrutura mínima de um site estático (HTML/CSS/JS) rodando localmente sem erros.
2. O projeto está conectado ao Netlify e cada push na branch principal gera um deploy automático.
3. Uma página inicial simples está acessível publicamente via URL do Netlify.

[Source: prd/epic-1-fundacao-catalogo.md#story-11-setup-do-projeto-e-pipeline-de-deploy]
